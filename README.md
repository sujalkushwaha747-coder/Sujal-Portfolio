# Self Portfolio

This is a standalone personal portfolio site built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` contains the page structure
- `styles.css` contains the full design system and responsive styles
- `script.js` contains all portfolio content plus the small interactive behaviors

## Customize

Edit the `portfolioData` object near the top of `script.js` to change:

- your name and headline
- project descriptions
- skills and certificates
- email, GitHub, and LinkedIn links

## Open Locally

You can open `index.html` directly in a browser, or serve the folder with any simple local server.
